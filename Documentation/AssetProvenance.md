The exclusion covers the known unresolved dependency families:

- project Addressable prefabs and entries `UI_LavaRush`, `UI_LavaRush_Icon`, and `UI_LavaRush_Cell`;

An excluded file may enter a later version only after ownership or compatible license evidence is recorded for that exact file, one canonical location is selected, the required `.meta` GUID/reference migration is approved, and package plus consuming-project validation passes.
