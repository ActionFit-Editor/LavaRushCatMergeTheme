# Third Party Notices

`com.actionfit.lava-rush.theme.catmerge@0.1.1` does not bundle third-party source code, image, font, audio, material, animation, prefab, or other binary content.

The package depends on `com.actionfit.lava-rush.ui`, which in turn uses Unity and declared ActionFit packages. Those dependencies retain their own licenses and third-party notices; their files are not copied into this package.

The fallback font is requested from Unity as `LegacyRuntime.ttf` at runtime and is not redistributed as a package file. Screen geometry is generated from UGUI primitives, and sound cues are synthesized at runtime from ActionFit-authored code.

See `Documentation/AssetProvenance.md` for the included-source matrix and the Cat Merge assets explicitly excluded from this release candidate.
